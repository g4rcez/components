# Heading acceptance criteria

Verify these in the consuming application. They are test targets, not proof of WCAG conformance.

1. **Given** a page with sections and subsections, **when** you inspect its heading outline, **then** each level reflects the actual hierarchy, including a meaningful page heading.
2. **Given** static headings, **when** the user presses Tab, **then** only associated interactive controls receive focus, in logical document order.
3. **Given** desktop or mobile heading navigation, **when** the user moves between headings, **then** the topic and structural level are available without visual styling.
4. **Given** a long title, **when** text is enlarged to 200% or the viewport narrows, **then** the title stays readable and associated actions stay reachable.
